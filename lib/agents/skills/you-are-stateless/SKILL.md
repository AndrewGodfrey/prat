---

You committed to a behavioral change. A fresh agent session won't inherit this conversation, so
"I'll treat it that way going forward" is a no-op unless it's recorded somewhere a later session
loads.

Before continuing:
- If it's a standing rule: record it — invoke the `remember` skill, or edit the relevant file
  directly if the home is obvious (e.g. a repo `AGENTS.md`).
- If it's one-time task direction: name that explicitly so the user knows you made the call.
